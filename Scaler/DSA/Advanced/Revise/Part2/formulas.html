Math Basics
GCD (Euclidean algorithm)
d21
gcd(a, b) = gcd(b, a % b) // until b == 0
gcd(a, 0) = a
Ex: gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6
When to reach for it
  • Reducing fractions / simplifying ratios
  • "Largest equal-size group" problems
  • LCM derivation (needs gcd)
  • Stride / cycle problems on arrays
Used in Maths Formulas LCM
Recursive form is O(log(min(a, b))). Iterative while (b != 0) { t = b; b = a % b; a = t; } avoids stack frames.
LCM (via GCD)
d21
lcm(a, b) = (a / gcd(a, b)) * b
Ex: lcm(4, 6) = (4 / gcd(4,6)) * 6 = (4 / 2) * 6 = 12
When to reach for it
  • Aligning two cyclic events
  • "Smallest number divisible by both"
  • Period of repeating patterns
Used in Maths Formulas
Always divide first, then multiply — a * b / gcd can overflow even when the result fits.
Sum of First N Natural Numbers
d21
1 + 2 + … + N = N * (N + 1) / 2
Ex: N = 10 → 10 * 11 / 2 = 55
When to reach for it
  • "Find the missing number in 1..N"
  • Counting total subarrays of an array (N*(N+1)/2)
  • Triangular number / staircase totals
  • Brute upper bound for staircase / sqrt problems
Used in bs-staircase bs-special-integer missing number variants
Always use long — N=10⁵ already gives ~5·10⁹, overflows int.
Sum of Squares 1..N
d21
1² + 2² + … + N² = N * (N + 1) * (2N + 1) / 6
Ex: N=4 → 4·5·9/6 = 30 (1+4+9+16)
When to reach for it
  • Closed-form for nested sums
  • Estimating brute-force work over partial sums
Total Subarrays of an Array
d27, d28
#subarrays(N) = N * (N + 1) / 2
Ex: N=4 → 4·5/2 = 10 subarrays
When to reach for it
  • Sanity-checking that "sum of contributions" equals total work
  • Choosing whether O(N²) enumeration even fits
Identical to "sum of 1..N" — every left endpoint l pairs with N - l right endpoints.
Inclusion–Exclusion (divisible by A or B)
d23
#(1..N divisible by A or B)
  = ⌊N / A⌋ + ⌊N / B⌋ − ⌊N / lcm(A, B)⌋
Ex: N=12, A=2, B=3 → 6 + 4 − 2 = 8 (numbers: 2,3,4,6,8,9,10,12).
When to reach for it
  • "K-th magical number divisible by A or B"
  • BS on answer where the predicate is "count ≤ mid ≥ K"
  • Any two-set "OR" count over [1..N]
Used in bs-magical-number
Subtraction prevents double-counting multiples of lcm(A,B). Generalizes to 3+ sets with alternating signs.
Binary Search
Safe Mid (no overflow)
d21–d23
mid = low + (high - low) / 2
Ex: low=2·10⁹, high=2·10⁹+8 → naive (low+high)/2 overflows int; safe form stays valid.
When to reach for it
  • Every binary search — no exception
  • Especially: BS on answer space where bounds can be 10⁹
Used in all bs-* problems
Mathematically equivalent to (low+high)/2 — but immune to int overflow when low, high are near MAX_INT.
Matrix Median Position
d23
target rank = (N * M + 1) / 2 // 1-indexed median in odd-size matrix
Ex: 3×5 matrix → (15+1)/2 = 8th smallest is the median.
When to reach for it
  • Median of a row-wise sorted matrix
  • BS on value range + per-row lower_bound
Used in bs-matrix-median
Lower Bound (count ≤ x in sorted row)
d23
count(≤ x) = upper_bound(row, x) − 0
count(< x) = lower_bound(row, x)
Ex: row = [3,8,14,22], x=10 → upper=2 (3,8 ≤ 10), lower=2 (same since 10 missing).
When to reach for it
  • Count "how many ≤ candidate" across N sorted rows in O(N log M)
  • BS-on-value-range driver function
Used in bs-matrix-median
Integer Square Root via BS
d21, d23
⌊√N⌋ = largest mid with mid * mid ≤ N
// search space: low=0, high=N (or 46341 cap if N fits in int)
// use (long) cast on mid*mid to avoid overflow
Ex: N=11 → mid=3 (9 ≤ 11 ✓), mid=4 (16 > 11 ✗) → 3.
When to reach for it
  • "⌊√N⌋ without Math.sqrt"
  • Staircase: smallest k with k(k+1)/2 ≥ N
  • Any "largest x with monotone predicate"
Used in bs-sqrt bs-staircase
Cast: long sq = (long) mid * mid; — int*int overflows when N ≥ 2³¹.
BS-on-Answer Bounds
d23
// minimize-max (painters, books, paint cost):
low = max(items) // can't go below largest single item
high = sum(items) // 1 worker takes everything

// maximize-min (aggressive cows):
low = 1 // smallest gap
high = max(items) − min(items) // widest possible gap
Painters [10, 20, 30, 40]: low=40, high=100. Feasible(70)? → yes → try 60.
When to reach for it
  • BS on answer space — picking the right bounds is half the work
  • Wrong bounds (low=0 or low=1 for minimize-max) → infinite-loop or wrong answer
Used in bs-painters bs-allocate-books bs-aggressive-cows
Pivot Detection in Rotated Sorted Array
d22
// At each step exactly one half is sorted:
if (A[low] ≤ A[mid]) → left half is sorted
else → right half is sorted

// Then check if target lies inside the sorted half:
if (target in [A[low], A[mid])) → go left, else → go right
Ex: A=[4,5,6,7,0,1,2], target=0. mid=3 (A[mid]=7). A[low]=4 ≤ 7 → left sorted, target 0 ∉ [4,7), go right.
When to reach for it
  • Search in a rotated sorted array (no duplicates)
  • Find min in rotated sorted array (same half-test)
Used in bs-rotated-search
Use <= not < on the left-sorted check — handles the case where low == mid.
Median by Partition (Two Sorted Arrays)
d23
// Let N ≤ M; BS over partitionA in [0..N]:
partitionA = (low + high) / 2
partitionB = (N + M + 1) / 2 − partitionA

// Valid when:
maxLeftA ≤ minRightB && maxLeftB ≤ minRightA

// Median:
odd → max(maxLeftA, maxLeftB)
even → (max(maxLeftA, maxLeftB) + min(minRightA, minRightB)) / 2.0
Ex: A=[1,3], B=[2]. N=1, M=2. Trying partitionA=1, partitionB=1 → maxLeftA=1, minRightB=∞, maxLeftB=2, minRightA=3 → valid → median = max(1,2) = 2.
When to reach for it
  • Median of two sorted arrays in O(log(min(N, M)))
  • K-th element of two sorted arrays (similar partition trick)
Used in bs-median-two-sorted
Use Integer.MIN_VALUE / MAX_VALUE as sentinels when a partition lands at the array edge.
Stack & Monotonic Patterns
Min-Stack Encode/Decode (O(1) extra space)
d26
// push x:
if (stack empty) → push x, min = x
else if (x >= min) → push x
else → push (2*x − min), min = x

// top:
if (top < min) → return min // encoded marker
else → return top

// pop:
if (top < min) → min = 2*min − top // recover old min
then pop
Why it works: when new x < min, store the "deviation" 2x−min. Since 2x−min < x < min, it acts as a sentinel; on pop we reverse to get the previous min.
When to reach for it
  • Min/Max stack with O(1) per op and O(1) extra space
  • Interview classic when "no auxiliary stack" is required
Used in stacks-min-stack
Use long if values can be near MAX_INT — 2*x − min can underflow int.
Contribution Technique — Subarray Sum
d27
contribution(A[i]) = A[i] * (i − L) * (R − i)
// L = prev boundary index, R = next boundary index
// (i − L) = # subarrays where i is the chosen left side
// (R − i) = # subarrays where i is the chosen right side
Why it works: every subarray (l, r) containing i has exactly one "i" — sum across all subarrays = Σ A[i] × (ways i is included).
When to reach for it
  • "Sum of f(subarray) over all subarrays"
  • f is min, max, sum, or count of a single element
  • Naive O(N²) or O(N³) is too slow
Used in stacks-max-and-min stacks-sum-of-subarray-mins queues-sum-of-min-max
L and R come from prevSmaller / nextSmaller (for min contribution) or prevGreater / nextGreater (for max contribution) — built once with a monotonic stack in O(N).
Contribution to Min & Max Stack Sum
d27
answer = Σ A[i] * (i − PG[i]) * (NG[i] − i)
       − Σ A[i] * (i − PS[i]) * (NS[i] − i)
// PG/NG = prev/next Greater · PS/NS = prev/next Smaller
Reads as: "every element contributes A[i] × (# subarrays where it's the max) MINUS A[i] × (# where it's the min)".
When to reach for it
  • Σ (max(sub) − min(sub)) over all subarrays
  • Distinct-element handling: use > on one side, >= on the other to avoid double-count
Used in stacks-max-and-min
Tie-breaking matters: for "next greater" use strict >, for "prev greater" use >= (or vice versa) so each subarray is counted exactly once.
Largest Rectangle in Histogram
d27
area(i) = H[i] * (NS[i] − PS[i] − 1)
answer = max over all i of area(i)
Ex: H=[2,1,5,6,2,3] → at i=3 (H=6): PS=2, NS=4, area = 6 * (4−2−1) = 6; at i=2 (H=5): PS=1, NS=4, area = 5*2 = 10 ← max.
When to reach for it
  • Maximum rectangle inside a bar chart
  • Building block for "max rectangle in binary matrix"
Used in stacks-largest-rectangle stacks-max-rectangle-binary-matrix
Sliding-Window Min / Max via Deque
d28
// Window is valid for i ≥ B − 1
answer[i] = A[deque.peekFirst()]
// Maintain decreasing deque for MAX, increasing for MIN
evict from front: while front index < i − B + 1
evict from back: while A[back] ≤ A[i] (for max)
Ex: A=[1,3,-1,-3,5,3,6,7], B=3 → max per window = [3, 3, 5, 5, 6, 7].
When to reach for it
  • Fixed-size window max/min in O(N) (not O(N·B))
  • Σ window-max + window-min over all windows
Used in queues-sliding-window-max queues-sum-of-min-max
Each index enters and leaves the deque at most once → amortized O(1) per step → O(N) total.
Tree & Recursion Identities
Balanced-Tree Check
d30
isBalanced(node):
  hL = height(left), hR = height(right)
  return |hL − hR| ≤ 1 && isBalanced(left) && isBalanced(right)

// O(N) trick: return -1 from height() if any subtree is unbalanced
heightOrFail(node):
  if (hL == -1 || hR == -1 || |hL−hR| > 1) return −1
Ex: tree with hL=2, hR=4 at root → |2−4| = 2 → NOT balanced.
When to reach for it
  • AVL property check (every node)
  • Any "no two subtrees differ by more than k"
Used in trees-balanced
The "-1 sentinel" trick avoids re-computing height per recursion call — turns O(N²) into O(N).
BST Validity (range carry)
d31
isBST(node, min, max):
  if (node == null) return true
  if (node.val ≤ min || node.val ≥ max) return false
  return isBST(left, min, node.val) && isBST(right, node.val, max)

// initial call: isBST(root, Long.MIN_VALUE, Long.MAX_VALUE)
Why long: a node with val = Integer.MIN_VALUE would fail the int-range check at the root — promote bounds to long.
When to reach for it
  • Validate BST property recursively
  • Any "every node must respect ancestor constraints"
Used in trees-valid-bst
Height of a Node
d29–d30
height(null) = −1 // or 0, depending on convention
height(node) = 1 + max(height(left), height(right))
Ex: single root → height = 0 (or 1). Leaf with two null kids → 1 + max(−1,−1) = 0.
When to reach for it
  • Max depth / min depth
  • Diameter of a tree (longest path through a node)
  • Balanced-tree check (|hL − hR| ≤ 1 at every node)
Used in trees-max-depth trees-balanced trees-diameter
Subtree Sum / Path Sum Recurrence
d29
subtreeSum(node) = node.val + subtreeSum(left) + subtreeSum(right)
pathSum(node, target) = pathSum(left, target − node.val) || pathSum(right, …)
Sum-tree check: node.val == subtreeSum(left) + subtreeSum(right) at every internal node.
When to reach for it
  • "Does any root-to-leaf path sum to B?"
  • Sum tree validation
  • Equal tree partition (split sum / 2)
Used in trees-path-sum trees-sum-binary-tree trees-equal-tree-partition
BST Range Pruning
d31
if node.val < L → recurse right only
if node.val > R → recurse left only
else → 1 + recurse(left) + recurse(right)
Why it's fast: we skip entire subtrees that can't contain a valid value — average O(log N + K) for K hits.
When to reach for it
  • "Count / list nodes in [L, R] inside a BST"
  • BST search, delete, validate — all use the same pruning idea
Used in trees-bst-nodes-in-range trees-search-bst trees-delete-bst-node
Level-Order Index Map (heap-style)
d30
// For a complete tree stored in array at index i (1-indexed):
left(i) = 2 * i
right(i) = 2 * i + 1
parent(i) = i / 2
0-indexed: left = 2i+1, right = 2i+2, parent = (i−1)/2.
When to reach for it

  • Heap implementation (priority queue)
  • Segment tree layout

Modular Arithmetic
Safe Modulo of Subtraction (avoid negatives)
d27, d28
result = ((a − b) % MOD + MOD) % MOD
Ex: a=3, b=10, MOD=7 → (-7 % 7 + 7) % 7 = 0. Without the +MOD, Java would return −0 or a negative depending on language.
When to reach for it
  • Any modular running sum that involves subtraction
  • "Max − min" contribution sums with mod
Used in stacks-max-and-min queues-sum-of-min-max
In Java, % on negatives returns negative — always wrap with + MOD) % MOD after any subtraction.
Modular Product (long cast)
d27
(a * b) % MOD = ((long)a * b) % MOD
Ex: a=b=10⁵, int * int overflows; (long)a * b = 10¹⁰ fits in long.
When to reach for it
  • Any product where both operands can reach √MAX_LONG
  • Contribution sums multiplying counts × values
Used in bs-add-or-not bs-painters bs-staircase bs-magical-number trees-valid-bst
