Binary Search on Sorted Array
d21, d22
Signals
  • Array is sorted; find target, position, or boundary
  • O(log N) required; brute O(N) scan is obvious
  • At any mid: can you tell the answer is left or right in O(1)?
  • Rotated sorted array; peak element; single in paired array
Core Skeleton 
low = 0; high = N - 1; ans = -1;
while (low <= high) {
    mid = low + (high - low) / 2;
    if (a[mid] == target)       { ans = mid; break; }
    else if (a[mid] < target)   low  = mid + 1;
    else                        high = mid - 1;
}
// For FIRST occurrence: on match → ans=mid; high=mid-1  (keep going left)
// For LAST occurrence:  on match → ans=mid; low=mid+1   (keep going right)
lower_bound variant 
// First index >= target
lb = N;
while (low <= high) {
    mid = low + (high - low) / 2;
    if (a[mid] >= target) { lb = mid; high = mid - 1; }
    else                    low  = mid + 1;
}
// Closest value: compare a[lb] and a[lb-1], take smaller |diff|
Critical: always low + (high-low)/2 not (low+high)/2. Always low <= high not <. Always ±1 on boundaries — never low=mid or high=mid.
Binary Search on Answer Space
d23
Signals
  • "Minimize the maximum" — painters, books, partitions
  • "Maximize the minimum" — aggressive cows, distance
  • The answer is a single number with a known min and max
  • You can write a yes/no check for any candidate in O(N)
3 questions to ask
  • Range? low = smallest valid answer, high = worst-case answer
  • Feasible returns? true = candidate works with given resources
  • Direction on success? minimize-max → go left; maximize-min → go right
Minimize-max Skeleton (painters, books) 
low = max(single element);  // never go below largest item
high = sum(all elements);   // 1 worker takes everything
ans = high;
while (low <= high) {
    mid = low + (high - low) / 2;
    if (feasible(mid)) { ans = mid; high = mid - 1; } // try smaller
    else               { low = mid + 1; }
}
return ans;
Feasibility Check (greedy) 
boolean feasible(int[] items, int workers, long mid) {
    int used = 1;
    long curr = 0;
    for (int x : items) {
        if (curr + x > mid) {
            used++;              // new worker
            curr = x;
            if (used > workers) return false;  // early exit INSIDE loop
        } else {
            curr += x;
        }
    }
    return true;
}
Maximize-min (cows): on feasible(mid) true → ans=mid; low=mid+1. On false → high=mid-1. Opposite direction from minimize-max.
Linked List — 3-Pointer Reverse
d25
Signals
  • Reverse a linked list in-place, O(1) space
  • Reverse a segment between positions B and C
  • Reverse every K nodes
Mental model
  • save — capture curr.next before breaking
  • flip — point curr backward at prev
  • slide prev — prev advances to curr
  • slide curr — curr advances to saved next
  • Loop ends when curr is null; prev is new head
Full Reverse 
prev = null;  curr = head;
while (curr != null) {
    next      = curr.next;  // 1. SAVE
    curr.next = prev;       // 2. FLIP
    prev      = curr;       // 3. SLIDE prev
    curr      = next;       // 4. SLIDE curr
}
return prev;  // new head
reverseBetween (positions B to C) 
dummy.next = head;
prevNode = dummy;
for (i = 1; i < B; i++) prevNode = prevNode.next; // stop at B-1

curr = prevNode.next;  prev = null;
for (i = 0; i <= C - B; i++) {   // reverse C-B+1 nodes
    next = curr.next; curr.next = prev; prev = curr; curr = next;
}
// ORDER MATTERS: tail first, then head
prevNode.next.next = curr;   // old-B (tail) → node after C
prevNode.next      = prev;   // node before B → old-C (new head)
return dummy.next;
reverseKGroup 
ListNode reverseKGroup(ListNode head, int k) {
    check = head;  count = 0;
    while (check != null && count < k) { check=check.next; count++; }
    if (count < k) return head;    // < k nodes left → return as-is

    curr = head;  prev = null;
    for (i = 0; i < k; i++) {
        next=curr.next; curr.next=prev; prev=curr; curr=next;
    }
    head.next = reverseKGroup(curr, k);  // head is now tail
    return prev;                          // prev is new head
}
Linked List — Dummy Node, Delete, Remove-Nth
d24, d25
Dummy Node
  • Head might change (insert at head, delete head)
  • Makes head ops identical to mid-list ops
  • Always return dummy.next — never return original head
deleteNode (no predecessor)
  • Copy next node's value into this node
  • Skip next node via node.next = node.next.next
  • Works only if node is not the tail
removeNthFromEnd
  • Fast starts N steps ahead of slow
  • Both advance until fast.next == null
  • Slow is now at the predecessor — skip next
Dummy Node Pattern 
dummy.next = head;
prev = dummy;  curr = head;
while (curr != null) {
    if (shouldDelete(curr)) prev.next = curr.next;
    else                    prev = curr;
    curr = curr.next;
}
return dummy.next;
deleteNode trick 
node.val  = node.next.val;       // overwrite with next's value
node.next = node.next.next;      // skip next node
removeNthFromEnd — two-pointer 
dummy.next = head;
fast = dummy;  slow = dummy;
for (i = 0; i < n; i++) fast = fast.next;  // gap of N
while (fast.next != null) {
    fast = fast.next;
    slow = slow.next;
}
slow.next = slow.next.next;  // delete N-th from end
return dummy.next;
Clone List with Random Pointer — 2-Pass HashMap
d25
Signals
  • Deep-clone a list where each node has a random pointer to any node
  • Random pointer can target any position — can't wire in one pass
Why 2 passes
  • Pass 1: create all clones (values only, no links yet)
  • Pass 2: wire next and random using map lookups
  • map.get(null) returns null — no null checks needed
  • Never write clone.next = curr.next — that points to the original
Skeleton 
// Pass 1: build original → clone map
Map<Node, Node> map = new HashMap<>();
curr = head;
while (curr != null) {
    map.put(curr, new Node(curr.val));
    curr = curr.next;
}
// Pass 2: wire links through the map
curr = head;
while (curr != null) {
    map.get(curr).next   = map.get(curr.next);    // null-safe
    map.get(curr).random = map.get(curr.random);  // null-safe
    curr = curr.next;
}
return map.get(head);
Stack — Match, Evaluate, Cancel
d26
Signals
  • Open-close pairs must match in order (brackets, braces)
  • Postfix expression — operands come before operators
  • Adjacent identical elements cancel each other
  • Need the most recently seen unprocessed item
Rules
  • Check isEmpty() before every pop and peek — always
  • Postfix order: pop b first, then a; apply a op b
  • Empty stack at end = valid / fully matched
Balanced Parentheses 
for (char c : s.toCharArray()) {
    if (isOpen(c))  stack.push(c);
    else {
        if (stack.isEmpty()) return false;   // no match
        if (stack.pop() != matchOf(c)) return false;
    }
}
return stack.isEmpty();
Postfix Evaluation 
for (String token : tokens) {
    if (isOperator(token)) {
        int b = stack.pop(), a = stack.pop();
        stack.push(apply(a, b, token));   // a op b, not b op a
    } else {
        stack.push(Integer.parseInt(token));
    }
}
return stack.pop();
Redundant Braces 
for (char c : s.toCharArray()) {
    if (c == ')') {
        boolean hasOp = false;
        while (stack.peek() != '(') {
            hasOp |= isOperator(stack.peek());
            stack.pop();
        }
        stack.pop();   // remove '('
        if (!hasOp) return true;  // redundant
    } else stack.push(c);
}
Monotonic Stack — Nearest Smaller / Greater
d27
Signals
  • "For each element, nearest smaller/greater to left or right"
  • Rectangle areas; contribution bounded by nearest boundary
  • Answer for each index depends on first element that breaks order
Key rules
  • Push indices not values — need distance, not just value
  • Pop while top violates the order you want to maintain
  • Each popped index found its answer: the current element i
  • Remaining in stack at end → no answer on that side (use 0 or N)
Next Smaller to the Right 
int[] nsr = new int[N];
Arrays.fill(nsr, N);          // default: no smaller to right
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < N; i++) {
    while (!stack.isEmpty() && a[stack.peek()] > a[i]) {
        nsr[stack.pop()] = i; // i is the next smaller for that index
    }
    stack.push(i);
}
Largest Rectangle in Histogram 
// Find NSL and NSR for each bar using two monotonic stack passes
// Width = nsr[i] - nsl[i] - 1
// Area  = height[i] * width
// Track max area across all bars
For NSL (prev smaller left): iterate right-to-left, or iterate left-to-right and pop while top ≥ current — the element remaining in stack is the answer for each index.
Deque — Sliding Window Maximum
d28
Signals
  • Fixed-size window slides; need max (or min) at each position
  • Elements expire after K steps; need oldest/best efficiently
Invariant
  • Deque stores indices in decreasing order of their values
  • Front = index of window maximum
  • Remove back when current ≥ back (back is useless — current is better and lasts longer)
  • Remove front when its index is outside the window
Sliding Window Maximum 
Deque<Integer> dq = new ArrayDeque<>();
int[] result = new int[N - K + 1];
for (int i = 0; i < N; i++) {
    // remove back while current is >= back (useless)
    while (!dq.isEmpty() && a[dq.peekLast()] <= a[i])
        dq.pollLast();
    dq.addLast(i);
    // expire front if outside window
    if (dq.peekFirst() < i - K + 1)
        dq.pollFirst();
    // record result once first full window is formed
    if (i >= K - 1)
        result[i - K + 1] = a[dq.peekFirst()];
}
Tree Recursion / DFS
d29, d30
Signals
  • Same logic applies at every subtree
  • answer = combine(left result, right result, node)
  • Path sums, subtree sums, structural checks (balanced, equal partition)
Sentinel pattern (isBalanced)
  • Return actual height normally; return -1 on unbalanced
  • Every call checks if (left == -1 || right == -1) return -1 before computing own height
  • Never use the value if it is the sentinel
Standard DFS Skeleton 
int solve(TreeNode node) {
    if (node == null) return NEUTRAL;    // 0 for sum, true for checks
    int left  = solve(node.left);
    int right = solve(node.right);
    // check sentinel BEFORE combining
    if (left == SENTINEL || right == SENTINEL) return SENTINEL;
    return combine(left, right, node.val);
}
Build Tree from Inorder + Preorder 
TreeNode build(int[] pre, int ps, int pe,
               int[] in,  int is, int ie,
               Map<Integer,Integer> inMap) {
    if (ps > pe) return null;
    int rootVal = pre[ps];
    int k = inMap.get(rootVal);       // root position in inorder
    int leftCount = k - is;
    TreeNode root = new TreeNode(rootVal);
    root.left  = build(pre, ps+1,          ps+leftCount,  in, is,   k-1, inMap);
    root.right = build(pre, ps+leftCount+1, pe,           in, k+1,  ie,  inMap);
    return root;
}
BST — Search, Validate, Build
d31
Signals
  • Tree with left < root < right property
  • Search in O(log N) average — discard half at each level
  • Validate BST ordering; build balanced from sorted array
Key points
  • Validate with long bounds — nodes can hold Integer.MIN/MAX_VALUE
  • Build: always mid as root → guarantees balanced height
  • Inorder of valid BST = sorted ascending — use this as a check
Search 
TreeNode search(TreeNode root, int val) {
    if (root == null || root.val == val) return root;
    return val < root.val
        ? search(root.left, val)
        : search(root.right, val);
}
Validate — Bound Propagation 
boolean isValid(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;
    return isValid(node.left,  min,      node.val)
        && isValid(node.right, node.val, max);
}
// call: isValid(root, Long.MIN_VALUE, Long.MAX_VALUE)
Build Balanced BST from Sorted Array 
TreeNode convert(int[] a, int lo, int hi) {
    if (lo > hi) return null;
    int mid = lo + (hi - lo) / 2;
    TreeNode root = new TreeNode(a[mid]);
    root.left  = convert(a, lo,    mid - 1);
    root.right = convert(a, mid+1, hi);
    return root;
}
// call: convert(a, 0, a.length - 1)
