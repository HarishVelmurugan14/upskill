Binary Search on Array d21, d22
Sorted array — find target, first/last occurrence, or insert position
Binary Search — low=0, high=N-1; on match save mid + keep going left/right for boundary
Sorted array — "first index ≥ X" or "closest value to X"
lower_bound — save mid when a[mid] >= target, move high=mid-1; check both lb and lb-1 at end
Sorted array, all values paired except one — find the solo element in O(log N)
Parity BS — if a[mid]==a[mid+1] and mid is even → single is right; else left; force mid to even index
Find peak element (greater than both neighbours) in O(log N)
Peak BS — if a[mid] < a[mid+1] peak is right (low=mid+1); else peak is at mid or left (high=mid-1, save mid)
Array was sorted then rotated — search for target in O(log N)
Rotated BS — check which half is fully sorted via a[low]<=a[mid]; if target in that half search there, else other half
Matrix where every row is sorted — find the median in O(N log M log max)
Value-space BS — binary search [0, 1B]; count elements ≤ mid per row with lower_bound; answer is first mid where count > N×M/2
Binary Search on Answer Space d23
Distribute N items among K workers — minimize the maximum any single worker handles
BS on [maxItem, totalSum] — feasibility: greedy left-to-right, new worker when sum > mid; early-exit inside loop when workers exceeded
Place K elements in sorted positions — maximize the minimum gap between any two
BS on [1, range] — feasibility: greedy, place next when gap ≥ mid; return true inside loop when all K placed; go right on success
Find longest window of size K such that no window sum exceeds B
BS on [0, N] — feasibility: sliding window of size mid; return false the moment any window sum > B; go right on success
Linked List d24, d25
Insert or delete nodes — head might change, want uniform code for head and mid
Dummy node — dummy.next = head; all ops including head-delete become prev.next = curr.next; return dummy.next
Reverse entire linked list in-place in O(N) O(1)
3-pointer reverse — save → flip → slide prev → slide curr; next=curr.next, curr.next=prev, prev=curr, curr=next; return prev
Delete a specific node — only the node itself is given, no predecessor
Copy-next trick — node.val = node.next.val; node.next = node.next.next; works only if node is not the tail
Deep-clone a list where each node has a random pointer to any node
2-pass HashMap — Pass 1: create all clones; Pass 2: clone.next = map.get(curr.next), clone.random = map.get(curr.random) (null-key safe)
Remove the Nth node from the end in one pass
Two-pointer gap — fast starts N ahead; both move until fast.next==null; slow.next = slow.next.next
Reverse only nodes between positions B and C
Dummy + reverseBetween — walk to B-1 (prevNode); reverse C-B+1 nodes; reconnect: tail first prevNode.next.next=curr, then prevNode.next=prev
Reverse every K nodes; leave the tail as-is if fewer than K remain
reverseKGroup recursion — count K (return as-is if fewer); reverse K; head.next = reverseKGroup(curr,k); return prev
Stack / Monotonic Stack / Deque d26, d27, d28
Match open-close pairs, evaluate postfix, or cancel adjacent duplicates
Stack — push on opening/value; pop and process on closing/operator; check isEmpty before every pop; empty stack at end = valid
For each element find the nearest smaller/greater to its left or right
Monotonic Stack of indices — pop while top violates order; each popped index just found its answer at current i; push indices not values
Sliding window maximum (or minimum) as the window moves
Deque of indices — remove back when current ≥ back (useless); remove front when outside window; front = window max
Need oldest and newest element efficiently; FIFO queue using two stacks
Two-stack queue — push to inStack; on dequeue if outStack empty, pour all from inStack; pop from outStack
Trees / BST d29, d30, d31
Hierarchical structure — same logic at every subtree; answer = combine(left, right, node)
Tree DFS — base: null → neutral; recurse left+right; check failure sentinel before combining; return result upward
Process nodes level by level; left view, level order, or width
BFS queue — enqueue root; each iteration dequeue node, process, enqueue children; track level by queue size snapshot
Rebuild tree from two traversals (inorder + pre/postorder)
Root from pre[0] or post[last]; find root in inorder → left count; split both arrays by left count; recurse
Tree with left < root < right — search, validate ordering, or build balanced
BST — search: go left/right by compare; validate: pass (long min, long max) bounds down; build from sorted: always pick mid as root
