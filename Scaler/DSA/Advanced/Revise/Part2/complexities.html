Pattern Every binary search on a sorted array is O(log N) — the range halves each step. Exceptions only appear when the problem adds work per step (matrix median: N·log M per check → N·log M·log max total) or changes the search space (staircase: the answer grows as √N, not log N).

Binary Search on Answer Space d23
paintersPartitionMinimumTimeToPaint
O(N log sum)O(1)
log(sum) BS steps × O(N) greedy feasibility check per step
aggressiveCowsLargestMinDistance
O(N log(max−min))O(1)
log(range) BS steps × O(N) greedy cow-placement per step

Pattern — all answer-space searches O(N · log range) every time. The outer binary search runs log(range) times. At each step a greedy scan touches every element once — O(N). They only differ in what "range" means: sum of elements (painters/books), positional spread (cows), or N itself (window length).

Monotonic Stack d27
largestRectangleInAHistogram
O(N)O(N)
Each bar pushed once, popped once — inner while is amortized O(1)
identifyMaxMinusMinInAllSubArrays
O(N)O(N)
Two mono-stack passes (NSL + NSR) O(N) each; contribution O(1) per element
nextGreaterValues / prevSmallerValues
O(N)O(N)
Single pass; each element pushed and popped at most once total
nextGreaterElementForSubsetQueries
O(N+M)O(N)
Build NGE map O(N); answer M queries via hashmap O(1) each
Key insight — why the inner while doesn't make it O(N²) Each element is pushed exactly once and popped at most once. Total push + pop operations = 2N across the entire pass. It doesn't matter how many times the inner while runs on any given iteration — the aggregate across all iterations is bounded by N.

Pattern Tree DFS is always O(N) time — every node is visited exactly once. Space is O(H) for the call stack (H = log N balanced, N worst case). BST operations are O(H) not O(N) because you discard one subtree at each node — the same reasoning as binary search.
