Kadane's Algorithm — Maximum Subarray d08 ▼
Signals in the question

The question asks for the maximum (or minimum) sum over all contiguous subarrays. The array can contain negative numbers — otherwise a simple total would suffice. You need O(N), not O(N²).

Standard solution skeleton

Maintain two variables: currentSum and maxSum. Walk left to right. At each element, add it to currentSum. If currentSum goes negative, reset it to 0 (there is no point carrying a negative prefix). Update maxSum = max(maxSum, currentSum) at every step. Return maxSum.

Prefix-Max + Suffix-Max — Rain Water Trap d08 ▼
Signals in the question

You need to know the maximum value to the left of each position AND the maximum to the right. The answer at each position depends on both sides independently. Computing both on the fly in one pass is tricky — precompute instead.

Standard solution skeleton

Build leftMax[i] = max of A[0..i] in a left-to-right scan. Build rightMax[i] = max of A[i..N-1] in a right-to-left scan. The contribution at index i = min(leftMax[i], rightMax[i]) − A[i]. Sum all contributions.

Difference Array — Range Update then Query d08 ▼
Signals in the question

Many range-update operations of the form "add value V to every index in [L, R]" are given upfront. Then you need to query the final array. Applying each update naively is O(N) per query — too slow for many updates.

Standard solution skeleton

Create a diff[] array of zeros. For each update [L, R, V]: diff[L] += V, diff[R+1] -= V. After all updates, take the prefix sum of diff[] — this gives the final value at every index in one O(N) pass.

In-Place Sign Marking — First Missing Positive d10 ▼
Signals in the question

Find a missing number in range [1, N] using O(1) extra space. The array itself can be used as a presence map — use the sign of each element to encode whether the corresponding index has been seen.

Standard solution skeleton

Pass 1: Replace all values outside [1, N] with N+1 (they are unusable). Pass 2: For each element whose absolute value v is in [1, N], negate A[v−1] to mark v as present. Pass 3: The first index i with A[i] > 0 means i+1 is missing.

XOR Tricks — Unique Elements in an Array d11, d12 ▼
Signals in the question

Every element appears an even number of times except one or two. XOR is self-inverse (A XOR A = 0) and identity-neutral (A XOR 0 = A), so pairs cancel out. This is the key property to exploit.

Standard solution skeleton

One unique: XOR all elements — pairs cancel, the unique value remains.

Two uniques (A, B): XOR all → get (A XOR B). Find the rightmost set bit in (A XOR B) — this bit differs between A and B. Partition the array by that bit; XOR each partition independently to find A and B.

Binary Exponentiation — Fast Power d14, d15 ▼
Signals in the question

Compute A^N where N can be up to 10^9. Linear multiplication would time out. The problem may also ask for the result modulo a large prime, which means you cannot rely on floating-point shortcuts.

Standard solution skeleton

If N is even: A^N = (A^(N/2))². If N is odd: A^N = A × A^(N−1). Recurse (or iterate) until the exponent reaches 0 (result = 1). Apply modulo after every multiplication to keep numbers small: result = (result * base) % mod.

Prefix Sum + HashMap — Subarray Sum Problems d16, d17 ▼
Signals in the question

Count (or find) subarrays with a specific sum. Two-pointer only works for non-negative arrays. For general arrays with negatives, prefix sums paired with a HashMap give O(N).

Standard solution skeleton

Maintain a running prefix sum. For each new prefix sum S, check if (S − target) exists in the map — if yes, that many subarrays ending here have sum = target. Add S to the map (store first-occurrence index for length queries). Initialize map with {0: −1} so subarrays starting at index 0 are handled correctly.

Merge Sort — Counting Inversions d18 ▼
Signals in the question

Count pairs (i, j) where i < j but A[i] > A[j]. Brute force is O(N²). Merge sort counts inversions as a side effect of sorting — whenever a right-half element is picked before remaining left-half elements, all those left-half elements form inversions with it.

Standard solution skeleton

Run merge sort normally. During the merge step, when you pick element from the right sub-array while the left sub-array still has elements remaining, add leftRemaining to the inversion count. Return total inversions along with the sorted array.

Dutch National Flag — Sort 0s, 1s, 2s d19 ▼
Signals in the question

Sort an array with only 3 distinct values in one pass. Counting sort works but takes two passes and requires knowing the range. DNF does it in one pass with three pointers.

Standard solution skeleton

Maintain three pointers: low (boundary of 0s), mid (current), high (boundary of 2s). When A[mid] == 0: swap A[low] and A[mid], advance both. When A[mid] == 1: advance mid only. When A[mid] == 2: swap A[mid] and A[high], retreat high (do not advance mid — the swapped value needs inspection). Stop when mid > high.
